Privacy notice

This draft documents the current local beta and static package. It is not publication-ready legal advice.

Effective date: [REPLACE BEFORE PUBLISHING: EFFECTIVE DATE] · Operator: [REPLACE BEFORE PUBLISHING: VERIFIED OWNER OR LEGAL ENTITY]

Draft status: a qualified human must verify the app, hosting, distribution, support, jurisdiction, and vendor facts; complete every placeholder; and approve this notice before publication.

1. Scope

This notice is intended to cover the SmartCart private iOS beta and this static informational website. It does not yet cover any future production retailer integration, account system, analytics service, hosted form, email platform, payment service, or public app distribution because none is represented in this package.

2. Current website behavior

The local static website package contains only HTML, CSS, JavaScript, and text files. It includes no analytics, advertising tags, cookies, remote images, third-party fonts, account system, or form endpoint. The contact-page demonstration prevents submission and does not transmit or store entered text.

Deployment can add server logs, content-delivery services, security systems, analytics, or form processing. Those choices must be documented here after a host and domain are selected.

3. Information the current beta stores locally

Based on the current unreleased validation candidate, SmartCart can save versioned JSON in the app’s Application Support directory. Saved state can include:

  • recipes, ingredients, serving choices, and import source details;
  • shopping and pantry preferences, including dietary and organic settings;
  • selected prototype store, fulfillment, ZIP code, pickup-day, and pickup-time choices;
  • shopping items, pantry inventory, preferred product matches, product records, replacements, saved manifests, and guided-handoff progress;
  • feature flags, bounded local tester events, and an optional preferred delivery-provider label used by experimental surfaces.

This draft does not claim that local app data is encrypted beyond protections provided by the device and operating system. Production security and backup behavior must be verified before publication.

4. Camera, photos, and text recognition

If a tester chooses a camera or photo-library import, the app requests the applicable iOS permission. The current beta uses Apple Vision text recognition for recipe images. Testers should avoid importing sensitive documents and should review recognized text for errors.

5. Recipe pages and external destinations

If a tester imports a recipe page, the device requests that third-party page so the app can look for supported recipe metadata. The page operator can receive ordinary request information under its own privacy practices. Blocked or unsupported pages may fail.

When a tester opens an exact product page, a retailer search, or a retailer home destination, they leave SmartCart for a third-party service. That service may collect information under its own terms and privacy notice. The current candidate does not authenticate to a retailer or submit a retailer cart.

6. Local diagnostics and development backend

The candidate can retain privacy-limited diagnostic funnel events inside its local JSON state for an internal tester dashboard. This is not a production telemetry or crash-reporting service. The current implementation bounds the local event list, but this draft does not treat that as a complete anonymization or compliance guarantee.

The repository also contains a credential-free local reference backend for development and automated tests. It can simulate accounts, sessions, OAuth state, manifests, analytics ingestion, and affiliate-link decoration in process memory. It is not connected to this static website, is not represented as a hosted service, uses no real provider token exchange, and loses in-memory data when restarted.

7. Accounts, affiliates, and sales

Production authentication, cloud sync, retailer credentials, hosted telemetry, and live affiliate attribution are not represented. This package does not claim sale or sharing of personal information, targeted advertising, or compensated affiliate tracking. A human legal review must reassess these statements if the product, local backend, or website is promoted or connected to production services.

8. Retention, deletion, and tester controls

Local app state persists across relaunch until it is replaced, reset, removed with the app, or otherwise cleared through approved test procedures. Exact deletion and device-backup behavior must be tested and documented before public release.
